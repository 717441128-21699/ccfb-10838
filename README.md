# Submask — 数据库子集抽取与脱敏工具

面向「测试环境想用生产数据、但不能直接拷库」的场景：从源库按业务条件抽取
一个**引用完整的子集**，对敏感字段做**格式合法、可复现**的脱敏，写入目标库。
当前源库 / 目标库均为 SQLite，核心层不依赖 Web，可独立调用，后续可替换连接层。

## 它解决的问题

- DBA 手工挑客户再改名，外键一断测试就跑不通 → **关系闭包抽取，引用到的行一条不落**。
- 脱敏后手机号少一位、身份证校验位错 → **按格式生成，校验位/Luhn 全部正确**。
- 同一个人在不同表被脱成不同名字，联调对不上 → **全局确定性字典，同值同假、跨表一致、重复作业一致**。

## 快速开始

```powershell
pip install -r requirements.txt

# 1. 生成 30 张表的演练源库 (含环形引用与未声明外键)
py scripts/generate_demo.py

# 2. 命令行端到端: 推断外键 -> 闭包抽取 -> 脱敏建库 -> 零错误校验
py scripts/demo_e2e.py

# 3. 网页
py run_web.py            # 打开 http://127.0.0.1:5000
```

## 网页五个页面

| 页面 | 功能 |
| --- | --- |
| 数据源 | 连接 SQLite，读出 30 张表、列、主键、已声明外键与行数 |
| 关系图 | 一键推断未声明外键（命名 + 实际数据重合度），人工勾选确认；力导向关系图，蓝线声明、橙线推断，可拖拽 |
| 抽取规则 | 表级 `seed` / `percent` / `reach` 三种模式 + 全局日期平移天数与脱敏 salt |
| 脱敏策略 | 按列选择 name / phone / id_card / bank_card / email / date |
| 作业记录 | 后台跑作业，查看每表抽取量（种子/闭包拆分）、脱敏覆盖、外键与格式校验结果 |

## 抽取规则语义

- **seed**：`WHERE` 条件选种子行，例如 `level_id >= 3 AND status='active'`。
- **percent**：大表对**可达行**做确定性等距抽样（非随机，重复运行结果一致）。
  抽样后该行引用的父行仍由向上闭包补齐，因此不会产生悬空外键。
- **reach**（默认）：不预置，只有被关系带到时才纳入，带到多少收多少。

闭包沿外键**双向**扩散到固定点：子→父补齐被引用的父行，父→子带出关联子行；
环形引用（客户↔地址、员工自引用、部门↔员工、订单自引用）靠集合收敛自然处理。

## 脱敏保证

| 策略 | 格式保证 |
| --- | --- |
| phone | 11 位、合法号段（13x/15x/18x…） |
| id_card | 18 位、真实地区码、**校验位正确**、保留原出生日期段 |
| bank_card | 保持原长度、**Luhn 校验通过** |
| name / email | 中文姓名 / 固定域邮箱 |
| date | 全局整体平移 N 天，**先后顺序与日期间隔不变**（对所有日期型列自动生效） |

- 映射持久化在状态库 `masking_dict` 表，配合固定 salt：**同一原值在所有表、
  所有作业中映成同一假值**；同策略内一一对应，不会把两个原值映成一个假值。

## 校验（作业报告）

每次作业对目标库执行：

1. `PRAGMA foreign_key_check` —— 外键完整性，要求 0 违约；
2. 手机号 / 身份证校验位 / 银行卡 Luhn 全量格式校验，要求 0 错误。

报告 JSON 落盘在 `reports/`，目标库在 `output/`，含每张表的源行数、种子行数、
闭包带入行数、占比，以及每个脱敏列的处理行数与不同假值数。

## 目录结构

```
submask/            核心库 (不依赖 Flask)
  schema.py         表/列/主键/声明外键读取
  inference.py      未声明外键推断 (命名规则 + 数据包含率)
  graph.py          关系图
  extraction.py     固定点闭包抽取 + 确定性等距抽样
  masking.py        确定性脱敏 (校验位/Luhn/日期平移/持久化字典)
  target_builder.py 目标库 DDL 合成 (含推断外键, 延迟约束) 与脱敏写入
  validator.py      外键检查 + 格式校验
  report.py         作业报告
  state.py          配置与作业历史持久化
  runner.py         作业编排 (后台线程)
  app.py            Flask REST 接口
scripts/            演练库生成、CLI 演示、HTTP 冒烟
static/             网页 (原生 HTML/CSS/JS, 无外部依赖)
tests/              pytest 验收 (20 个用例)
```
